La superficie de chat de página completa se incrusta con el shortcode
`[mga_chat_app]`. **Cada bot tiene su propio shortcode** — no hay
"un shortcode para todo". La pestaña Incrustar genera el snippet con
el bot que tienes seleccionado en el desplegable Espacio del bot.

<Aside type="caution" title="Cambia el desplegable para cambiar de bot">
  Si quieres el shortcode de **otro bot**, debes cambiar primero el
  desplegable **Seleccionar bot** en la barra lateral del espacio. La
  pestaña Incrustar siempre muestra el snippet del bot cargado en ese
  momento — no es un campo genérico de copiar/pegar.
</Aside>

## Dónde vive el shortcode

<Steps>
1. **Abre el personalizador** del bot que quieras incrustar. (`MGA WP →` elige un bot en el desplegable.)

2. **Haz clic en "Incrustar"** en las Secciones del chat de la barra lateral.

3. **Copia** el valor del campo de solo lectura. El shortcode contiene el `public_id` portátil del bot, así que funciona tras reinstalaciones e incluso en otros sitios WordPress que compartan la misma cuenta de MyGPT Assistants.

4. **Pega** en el bloque Gutenberg de tu elección (un bloque Shortcode, un bloque HTML personalizado o el editor clásico). Guarda la página. Vísitala — la superficie del chat se renderiza inline.
</Steps>

## Cambiar de bot = cambiar de shortcode

Si eliges otro bot en el desplegable, la pestaña Incrustar regenera el
snippet con el `public_id` de ese bot. No hay un "shortcode global del
plugin" — cada bot tiene el suyo.

## Overrides por incrustación (avanzado)

El shortcode `[mga_chat_app]` también acepta overrides de atributos
por incrustación — útil cuando quieres que el mismo bot se renderice
distinto en distintas páginas (p. ej. tema oscuro en marketing, ancho
más estrecho en una barra lateral).

| Atributo | Tipo | Ejemplo |
|---|---|---|
| `public_id` | string | `public_id="a8d3-…-f72c"` — requerido (o `bot_id="N"`). |
| `height` | px / vh / % | `height="100vh"` |
| `theme` | `light` / `dark` / `auto` | `theme="dark"` |
| `primary_color` | hex | `primary_color="#3b82f6"` |
| `max_width` | longitud CSS | `max_width="640px"` |
| `sidebar` | `true` / `false` | `sidebar="false"` |
| `require_wp_login` | `true` / `false` | `require_wp_login="true"` |
| `submit_on_enter` | `true` / `false` | `submit_on_enter="false"` |

Ejemplo:

```html
[mga_chat_app public_id="a8d3-…-f72c" theme="dark" max_width="640px" sidebar="false"]
```

Los atributos solo sobreescriben la configuración para esa incrustación
concreta. La configuración guardada en el personalizador no se modifica.

Siguiente: **[Requerir inicio de sesión en WordPress →](/es/wordpress/require-wp-login/)**.
