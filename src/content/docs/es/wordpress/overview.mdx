Esta sección recorre el plugin **MGA WP** desde la perspectiva del
administrador de WordPress — cada captura aquí es una réplica HTML en
vivo de la interfaz del plugin, no una imagen estática, así que las
etiquetas y el diseño siempre coinciden con el plugin publicado.

<Aside type="tip" title="Dos modos de incrustación">
  El plugin MGA WP incluye *dos* modos de incrustación: un **widget
  flotante** (burbuja de chat en la esquina inferior que sigue a los
  visitantes por todo el sitio) y una **superficie de chat de página
  completa** renderizada con el shortcode `[mga_chat_app]`. Los
  tutoriales siguientes se centran en la superficie de página completa
  y en la interfaz de espacio de bot compartida; el widget flotante
  tiene su propia página.
</Aside>
