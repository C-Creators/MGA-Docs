This section walks through the **MGA WP** plugin from the WordPress admin's
perspective — every screenshot is a live HTML replica of the plugin UI,
not a static image, so you can hover and read the same labels you'll see
once the plugin is installed on your site.

<Aside type="tip" title="Heads up">
  The MGA WP plugin ships *two* embedding modes: a **floating widget**
  (bottom-corner chat bubble that follows visitors across your site) and
  a **full-page chat surface** rendered via the `[mga_chat_app]`
  shortcode. The tutorials below focus on the full-page surface and the
  shared workspace UI; the floating widget has its own page.
</Aside>

## The workspace, in 30 seconds

Every page of the plugin lives inside the same shell: a left **workspace
sidebar** with a brand card, a "Select bot" dropdown, and a sub-nav for the
currently selected bot. The dropdown is the single source of truth — every
field you edit and every shortcode you copy belongs to the bot picked here.
